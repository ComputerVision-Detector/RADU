# 추가 이미지 전사

현재는 `labels/hf-XXXX.json`에 이미지별 정답 파일도 준비되어 있습니다. 기존 검수 5장은 내용이 채워져 있고 나머지 117장은 미라벨 양식입니다. 개별 파일 작성을 권장하며 통합 양식과 동시에 수정하면 서로 자동 동기화되지 않는 점에 유의하세요.

images/에 고정된 HF revision의 전체 122장을 모았습니다. 기존 검수 5장은 hf-0003, hf-0014, hf-0035, hf-0081, hf-0094입니다. 나머지 117장용 입력 양식은 references.additional.template.json입니다. 전체 목록·원본 행·이미지 해시는 additional_images.manifest.json에 있습니다. 기존 manifest.json과 references.json은 5장 평가용으로 유지합니다. 추가 양식은 기존 평가에 자동 포함되지 않습니다.

전사는 원본 이미지만 보고 작성하고, 모델 출력을 베끼지 않습니다. id는 파일 이름 그대로 유지합니다. text에 전사하고 검수 후 status를 verified로 바꾸세요. 판독 불가능한 페이지는 draft로 남기고 notes에 이유를 기록하세요. 특이사항이 없으면 notes는 빈 문자열입니다. JSON 문자열 내 따옴표는 \"로, 줄바꿈은 \n으로 표시합니다.

122장을 모두 지금 라벨링할 필요는 없습니다. 우선 개발용 10~20장과 별도 최종 평가용 약 10장을 선택해 ID를 고정하세요. 최종 평가용은 규칙 조정에 사용하지 않습니다. 이미지 해시가 같은 중복 또는 같은 원본의 변형은 서로 다른 분할에 배치하지 않습니다.

텍스트 기준을 먼저 통일하세요: 읽기 순서, 포스트잇 포함 여부, 괄호·주석 포함 여부, 곱셈 기호 표기, 반복부호 유지 여부. 표는 위에서 아래로 행 순서, 각 행은 왼쪽에서 오른쪽으로 전사하고 셀 사이 구분은 탭(\t), 행 사이는 줄바꿈(\n)을 권장합니다. 변경한 기준은 기존 정답에도 일관되게 적용해야 비교가 가능합니다. 화살표 선 자체를 text에 넣지 않더라도 화살표에 붙은 글자는 전사합니다. 제외하는 내용은 notes에 명시합니다.

표·화살표의 구조 평가는 text와 별도로 기록해야 합니다. 표의 경우 table_id, bbox, 각 cell의 row/col/rowspan/colspan/bbox/text가 필요합니다. 화살표는 arrow_id, path 좌표, head 위치, source_id, target_id, direction이 필요합니다. 모든 좌표는 원본 이미지 픽셀 기준으로 저장하고, 연결이 불명확하면 source_id/target_id를 null로 두며 임의로 연결하지 않습니다. 이것은 권장 설계이며 현재 전사 평가기의 입력 스키마가 아닙니다.

# RADU 최종 LoRA 학습 평가 결과 (validation)

Qwen3-VL-4B-Instruct + LoRA(r16, q/k/v/o), 설정 `configs/qwen3_vl_4b_lora_final.json`. 학습은 2026-11-07 02:49에 시작해 2026-11-09 01:40에 step 19,347/23,438에서 중단했다. checkpoint는 2,000 step마다 저장됐다. 학습 경위와 결정은 [`docs/RADU_TRAINING_HANDOFF.md`](../../../docs/RADU_TRAINING_HANDOFF.md)에 있다.

**결론:** 채택안은 방법 2다. 도식(노드·화살표·관계)은 checkpoint-6000, 수식·표는 checkpoint-18000 adapter를 쓴다. test split은 아직 평가하지 않았다. 아래는 모두 validation 결과이고, source당 최대 20장(합계 311장)이다.

병합 adapter는 6000과 18000 LoRA를 0.5/0.5로 정확히 가중합한 것이다(`src/training/merge_adapters.py`). hdBPMN과 cTDaR는 좋아졌지만 hdFlowmind 노드는 두 원본보다 낮아져(.857) 희석 위험이 있어 채택하지 않았다.

## 채점 기준

- **F1:** `src/training/evaluate.py`가 계산한다.
  - 노드는 종류가 같고 IoU 0.5 이상이면 맞음.
  - 화살표는 시작점과 끝점이 이미지 대각선의 3% 이내면 맞음. 끝점 정답이 없는 hdFlowmind는 bbox IoU 0.5로 본다.
  - 관계는 매칭된 노드 쌍이 일치하면 맞음.
  - 표는 셀의 (행, 열, rowspan, colspan) 일치, 수식은 공백만 무시한 LaTeX 완전 일치다.
- **mAP:** `src/training/box_ap.py`가 계산한다.
  - COCO 방식 AP를 IoU .50~.95에서 평균하고, 범주별로 평균한다.
  - 모델이 confidence를 내지 않아 모든 상자의 점수가 같다. 그래서 검출 모델의 공식 AP와 같은 기준으로 비교할 수 없다.
  - 수식 crop 4종(CROHME, HME100K, MathWriting, UniMER)은 정답 상자가 이미지 전체라 제외했다.
- **잡음:** source당 20장이라 수식은 1장이 .05에 해당한다.

## 학습 중 eval loss

[`eval_loss_by_step.csv`](eval_loss_by_step.csv)는 source당 20장 기준 eval loss다. 도식 6종은 step 4000이 최저였고 이후 계속 올랐다. 하지만 생성 F1은 6000이 가장 높았으므로, checkpoint는 loss가 아니라 생성 지표로 골라야 한다. 도식 이미지는 train 기준 132~619장뿐이라, step 6000까지 장당 약 14~41회, 18000까지 약 41~122회 반복 학습됐다.

## 파일

| 경로 | 내용 |
|---|---|
| `<run>/metrics.json` | source별 정밀도·재현율·F1과 맞음/예측/정답 개수 |
| `<run>/box_ap.json` | source·범주별 AP50/AP75/mAP |
| `<run>/predictions.jsonl` | 이미지별 모델 원문 출력과 점수. 다시 채점할 수 있다 |
| `merged-6000-18000-w55/merge.json` | 병합에 쓴 adapter와 가중치 |
| `samples/` | source마다 1장씩, 정답(왼쪽)과 예측(오른쪽). 도식은 6000, 수식·표는 18000 |
| `eval_loss_by_step.csv` | 학습 중 source별 eval loss |

`<run>`은 `ckpt-2000`, `ckpt-4000`, `ckpt-6000`, `ckpt-18000`, `merged-6000-18000-w55` 중 하나다.

평가 이미지 전체(실행당 311장, 약 240MB)와 모델 가중치는 용량 때문에 저장소에 넣지 않았다. 원본 위치는 학습 머신의 `models/radu/eval_final/<run>/images/`와 `models/radu/qwen3-vl-4b-lora-final/`이다. 이미지는 `predictions.jsonl`과 validation 데이터로 다시 그릴 수 있다(`python -m src.training.render_eval`).

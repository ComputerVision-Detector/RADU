# 브라우저 기능 검사 화면

실제 손글씨 이미지를 표시한 데스크톱·모바일 기능 검사 스크린샷이다. 화면의 `브라우저 검증 A` 전사와 6장 완료 표시는 별도 QA 저장소에서 만든 가상 입력이며 실제 정답이나 실서비스 진행률이 아니다. 배포 seed는 기존 검수 5장 / 미완료 117장을 유지한다.

두 사용자 작업 잠금, 임시 저장·재접속, 검수 완료, ZIP 내부 JSON, 보호된 5장, 브라우저 초안 복원, 모바일 콘텐츠 가시성·가로 넘침과 JavaScript 오류를 확인했다. QA 로컬 상태 파일은 Git에서 제외한다.

독립 서버 추가 후 Docker 컨테이너에서도 같은 두 브라우저 검사를 수행했다. 데이터는 별도 QA Docker 볼륨에만 저장했다. 컨테이너 재생성과 백업·복원 후 전사 유지도 확인했다.

## 1. 제품이 현재 제공하는 것

RADU 웹은 이미지 분석 결과를 SVG 캔버스 위에서 검토·편집하는 단일 페이지 앱이다. 분석 없이 빈 캔버스를 만들고 기본 순서도 요소를 수기로 놓는 경로도 있다. FastAPI가 프런트엔드 파일을 제공하고, 이미지 분석·세션 저장·내보내기를 처리한다.

현재 편집 데이터는 image, elements, relations, warnings를 가진 JSON 문서다. 요소는 Text, Box, Arrow이며 Box 기호는 처리, 시작·종료, 판단, 입력·출력, 문서, 데이터베이스, 서브프로세스, 수동 입력, 준비, 연결자, 지연 11종이다. 요소의 위치는 픽셀 기준 바운딩 박스로 기록한다.

## 2. 화면에 구현된 영역과 버튼

### 상단 바

- RADU 제품 표시.
- 프로젝트 이름 입력.
- 변경 저장 상태 텍스트.
- JSON 파일 열기.
- 서버에 저장된 문서 목록 열기.
- 현재 편집 문서 저장.
- JSON·SVG·PNG·PDF 내보내기 메뉴.

### 왼쪽 패널

- 빈 캔버스 새로 만들기.
- 이미지 선택 및 분석 진입.
- 업로드 영역 클릭 및 드래그 앤 드롭.
- 이미지 교체.
- 이미지 분석 결과 또는 직접 작성한 순서도의 요소·화살표를 대상으로 관계 분석 재실행.
- OCR 엔진 선택: OCR 미사용, PaddleOCR v6, PaddleOCR-VL 1.6, CLOVA OCR.
- 추론 장치 선택: CPU, GPU 0, GPU 1.
- 분석 요약: Text, Box, Arrow, relation 개수 및 검토 항목 개수.
- 요소 목록 및 유형 필터: 전체, Text, Box, Arrow.
- 빠른 도형 추가 버튼은 현재 선택한 기호를 추가하고, 기존 요소와 겹치지 않는 빈 위치를 탐색한다.

### 중앙 작업 영역

- 선택/이동, 캔버스 이동, 격자 맞춤 도구.
- 텍스트, 11종 순서도 기호, 화살표, 두 도형 연결, 서식 복사 도구.
- Undo, Redo, 다중 요소 정렬 메뉴.
- 원본/분석 오버레이/복원 결과 보기 전환.
- PaddleOCR-VL을 선택하면 OpenCV 검출과 RADU 관계 분석을 건너뛰고, VL 텍스트·위치만 오버레이한다. `RADU 복원`은 현재 미실행 상태를 표시하는 자리표시자다. 다른 OCR 엔진에서는 기존 OpenCV 검출·관계 분석을 유지한다.
- PaddleOCR-VL 분석은 CMD에 실제 Paddle/CUDA 장치, 모델, 입력 크기, 텍스트 줄 수 및 유효한 박스 수를 출력한다.
- 축소, 확대, 화면 맞춤.
- SVG 캔버스와 이미지 미리보기.
- 처리 중 표시와 상태 문구.

### 오른쪽 검사 패널

- 요소 속성 탭: 선택 요소의 내용, 유형, 위치, 크기, 신뢰도.
- 관계 탭: relation의 종류, 출발/도착 요소, 확인 상태 변경 및 relation 삭제.
- 검토 탭: 경고 목록과 경고가 가리키는 요소 선택.
- 선택 요소 삭제 및 변경 적용 버튼.

## 3. 이미지 입력과 분석

### 프런트엔드 입력 동작

- 브라우저에서 이미지 파일을 고르고 미리보기한다.
- SVG와 브라우저/Pillow가 지원하는 래스터 이미지 파일을 선택할 수 있다. PDF는 직접 분석 입력으로 지원하지 않는다.
- 애플리케이션 수준의 파일 크기·픽셀 수 상한을 두지 않는다. 실제 처리는 사용 가능한 메모리·저장 공간·분석 시간에 제한된다.
- 브라우저가 미리보기하지 못하는 형식은 미리보기 없이 서버에 업로드해 디코딩을 시도한다.
- 새 이미지 선택으로 기존 이미지를 교체한다.
- 미저장 편집이 있을 때 새 캔버스·이미지·JSON·저장 문서를 열면 확인 창을 띄운다.
- 브라우저 object URL은 이미지 교체/문서 전환 시 해제한다.

### 분석 요청 동작

- 분석 시작 버튼은 이미지가 없으면 오류 토스트를 표시한다.
- 분석 중 버튼을 비활성화하고 캔버스 위에 대기 오버레이를 표시해 중복 요청을 막는다.
- 선택한 OCR 엔진과 추론 장치를 `/api/analyze`에 전달한다.
- 성공 시 분석 문서를 열고 초기 편집 이력을 설정한다.
- 실패 시 상태 바와 토스트에 오류를 표시하며 버튼을 다시 활성화한다.
- 진행률은 단계별 숫자로 제공하지 않고, 전체 작업 중이라는 표시만 제공한다.

### 백엔드 분석 동작

- 허용 엔진: `none`, `paddleocrv6`, `paddleocrvl16`, `clova`.
- 허용 장치: `cpu`, `gpu`, `gpu:<index>`.
- SVG는 CairoSVG와 시스템 Cairo를 통해 PNG로 변환한 후 분석한다. Pillow가 지원하는 래스터 형식을 받고 AVIF 및 HEIF/HEIC 디코더를 의존성에 포함한다. PDF는 직접 입력으로 지원하지 않는다.
- 업로드 파일 크기나 픽셀 수를 고정값으로 제한하지 않는다. 대형 이미지 변환·추론은 호스트 메모리와 저장 공간을 소모한다.
- 원본을 저장하고 EXIF 회전 방향을 반영해 RGB로 정규화한다.
- PaddleOCR-VL 사용 시 결과 문서의 요소는 VL 텍스트·위치만 포함하며 RADU 도형·화살표·관계 분석은 수행하지 않는다.
- 다른 OCR 엔진 또는 OCR 미사용 설정은 기존 OpenCV 후보 검출과 RADU 관계 추론 경로를 유지한다.
- 분석 모드, 원본/전처리 이미지 경로, 세션 ID, 생성 시각을 문서에 기록한다.
- 분석을 별도 Python worker 프로세스에서 수행한다. 기본 제한 시간은 900초이며 만료·실패 때 작업 파일을 정리한다.
- OCR 예외는 전체 구성요소 결과를 폐기하는 대신 OCR 경고에 기록한다.

### 현재 분석기의 실제 한계

- 가중치가 없을 때 검출은 학습된 RADU 모델이 아니라 OpenCV 후보 생성 방식이다. 후보의 confidence는 휴리스틱 수치이며 정확도 보증이 아니다.
- OpenCV는 도형 후보와 화살촉처럼 보이는 Hough 선분 조합을 제안한다. 필기체·겹침·희미한 선·노트 줄에서 오검출/누락이 가능하다.
- PaddleOCR-VL 1.6은 현재 `Spotting:` 경로에서 텍스트와 텍스트 위치를 제공한다. 웹의 VL 비교 모드는 이 출력만 표시하며, 도형·화살표·관계 복원은 현재 의도적으로 실행하지 않는다.
- 도형 내부 텍스트 배치·포함 관계와 화살표 연결 대상은 자동 추론 결과이므로 항상 정확하다고 보장하지 않는다.
- 전처리는 서버에서 자동 수행한다. 사용자가 회전·밝기·원근·크롭 강도를 조절하거나 보정 전후를 직접 비교하는 컨트롤은 없다.

## 4. 빈 캔버스 수기 작성과 도형 렌더링

### 새 요소 생성

- 빈 캔버스 기본 크기는 1600 × 1000 픽셀이다.
- 도구를 고른 뒤 캔버스에서 드래그하면 Text, Box 또는 Arrow를 만든다.
- 도형 도구는 드래그 방향이 반대여도 좌상단·우하단을 정렬해 바운딩 박스를 만든다.
- 짧은 클릭은 기본 크기 요소로 처리한다. Text는 최대 180 × 42, Box는 최대 130 × 58 픽셀 기본 크기를 사용한다.
- Arrow는 시작점과 끝점 간 길이가 8픽셀보다 짧으면 생성하지 않는다.
- 도형·텍스트·화살표 도구는 여러 요소를 연속 생성하도록 유지한다. V 또는 Escape로 선택 모드로 돌아온다.
- Text 기본 라벨은 `새 텍스트`, process는 `새 단계`, decision은 `조건 입력`, terminator는 `시작 / 종료`다.
- Arrow는 드래그한 두 끝점으로 만들어지고, 양 끝점마다 가장 가까운 Box를 찾아 flows_to relation의 source/target으로 지정한다.
- 화살표 끝에 가까운 도형을 찾지 못하면 null 연결 및 검토 경고를 기록한다.
- 별도 연결 도구는 첫 번째 Box, 두 번째 Box를 차례로 클릭해 연결을 만든다. 같은 도형을 다시 고르면 연결을 취소한다.

### 현재 모양 불일치(사용자 지적 사항)

- 시작·종료 기호는 캡슐형 SVG 미리보기로 표시한다. 입력/출력 평행사변형 및 수동 입력 사다리꼴과 구분한다.
- 실제 캔버스의 `terminator` 렌더링은 `rx = 높이 / 2`인 둥근 직사각형이다. 가로가 충분히 넓으면 캡슐/알약 모양이고, 너비와 높이가 비슷하면 원형처럼 보인다.
- SVG 내보내기도 terminator를 둥근 직사각형으로 출력한다.
- 도형 선택 미리보기, 캔버스 표시, SVG/PDF 출력은 같은 shape 유형을 유지한다.

### 현재 지원하는 도형 종류

- 처리 도형: 둥근 모서리 직사각형.
- 판단 도형: 마름모.
- 시작·종료 도형: 캡슐형 둥근 직사각형.
- 별도 텍스트 박스.
- 직선 화살표.
- 11종의 순서도 기호와 스타일/회전/화살표 경로 설정을 지원한다. YOLO 클래스명에 기호 정보가 있으면 분석 결과에 반영한다.

## 5. 선택·이동·크기 변경·텍스트 편집

### 선택 및 이동

- 요소 클릭으로 단일 선택한다.
- Shift/Control/Command 클릭으로 다중 선택에 추가하거나 해제한다.
- 빈 캔버스에서 드래그해 바운딩 박스가 사각 선택 영역과 겹치는 요소들을 고른다.
- 선택 요소를 드래그해 이동한다. 다중 선택은 선택된 요소를 함께 이동한다.
- 요소는 캔버스 범위 안에서 움직이도록 이동량을 제한한다.
- Box를 이동/크기 변경하면 relation에 연결된 Arrow의 끝점을 도형 경계 쪽으로 다시 계산한다.
- 관계 갱신은 해당 relation을 확인 필요/수정 상태로 표시한다.
- `V`로 선택 도구, Space를 누른 채 드래그하거나 손 도구로 캔버스를 이동한다.

### 크기 변경

- 단일 Text/Box에는 8개 핸들을 표시한다.
- 핸들 드래그 시 최소 크기와 캔버스 범위를 적용한다.
- 속성 패널의 X/Y/W/H에 숫자를 입력해 위치와 크기를 바꿀 수 있다.
- 크기 입력은 캔버스 범위, 양수 폭·높이인지 검사한다.
- Arrow에는 일반 사각형 크기 핸들 대신 시작점·끝점 핸들이 있다. 핸들을 옮기면 가까운 Box에 relation 대상을 다시 지정하고 가까운 도형이 없으면 해당 끝의 relation 대상을 비운다.
- 격자 맞춤이 켜져 있으면 이동/생성 시 10픽셀 격자에 맞춘다.

### 텍스트 편집

- Text 요소는 속성 패널 textarea에서 편집한다.
- Box 라벨은 속성 패널 input에서 편집한다.
- Box/Text를 캔버스에서 더블클릭하면 캔버스 위 textarea가 열리도록 구현되어 있다. Enter는 줄바꿈, Ctrl/Cmd+Enter는 저장, Esc는 취소, 포커스 이탈은 저장이다.
- OCR에서 원문 문자열과 수정 문자열이 다르면 원문을 별도 표시한다.
- 글꼴 크기/색/정렬, 도형 채우기/테두리/선 굵기, 회전, Arrow 경로/선 종류/라벨을 편집할 수 있다. 글꼴 패밀리, Bold/Italic, 자동 크기 조절은 없다.
- 캔버스 위 편집 입력은 코드에 구현되어 있으나, 이번 환경에서는 Chrome 실행 권한 오류로 실제 더블클릭 회귀 검증을 하지 못했다.

## 6. 관계·검토 패널

- JSON relation 종류는 `flows_to`, `contains`, `near_text`다.
- 관계 탭에서 relation의 source/target을 드롭다운으로 변경할 수 있다.
- flows_to source/target 후보는 Box, 텍스트 포함/인접 관계의 target 후보는 Text다.
- 검수 상태는 미확인, 확인 완료, 보류, 수정됨으로 기록한다.
- 흐름 relation 수정 시 associated Arrow의 끝점과 direction을 갱신한다.
- relation 삭제 시 다른 relation이 같은 Arrow를 참조하지 않으면 해당 Arrow 요소도 삭제한다.
- 검토 탭에서 경고를 누르면 연결된 요소를 선택한다.
- 자동 경고 개수와 review 상태 수를 별도 계산하는 것이 아니라 warnings와 pending review flows_to를 합쳐 요약한다.
- 별도 오류 비교 엔진, 원본 근거 crop/하이라이트, 누락 관계 자동 비교, 검수 이력 타임라인은 구현되어 있지 않다.

## 7. 다중 선택, 정렬, 복사, 삭제, 키보드

- Ctrl/Cmd+A: 전체 요소 선택.
- Ctrl/Cmd+C, Ctrl/Cmd+V: 선택 요소 복사/붙여넣기. 붙여넣기 시 24픽셀 이동 및 새 ID를 부여한다.
- Ctrl/Cmd+D: 선택 복제.
- Delete/Backspace: 선택 요소와 그 요소를 참조하는 relation/arrow 삭제.
- Ctrl/Cmd+Z: Undo. Ctrl/Cmd+Shift+Z 또는 Ctrl/Cmd+Y: Redo.
- 이력은 최대 80개 문서 상태를 보관한다.
- 방향키로 선택한 비-Arrow 요소를 1픽셀 이동하고 Shift+방향키는 10픽셀 이동한다. 연결 Box에 매달린 화살표는 따라간다.
- 정렬 메뉴: 왼쪽/가운데/오른쪽 정렬, 위/가운데/아래 정렬, 가로·세로 균등 배치.
- 균등 배치는 3개 이상 요소에서만 수행한다.
- 선택 영역은 요소 바운딩 박스가 선택 사각형과 조금이라도 겹치면 선택한다. 완전히 포함된 요소만 고르는 모드는 없다.
- 그룹/레이어/다중 페이지, 자유곡선, 임의 이미지 객체, 우클릭 메뉴는 아직 없다.

## 8. 확대·축소 및 원본 보기

- 확대/축소 버튼으로 현재 값에 1.15배 또는 1/1.15배를 적용하며 12%~300% 범위를 사용한다.
- Ctrl/Cmd+마우스 휠 확대/축소는 포인터 위치를 기준으로 캔버스 스크롤을 보정한다.
- 화면 맞춤은 캔버스 영역 크기와 문서 픽셀 크기로 zoom을 계산한다.
- 원본, 오버레이, 복원 결과를 순환한다. 오버레이는 전처리 이미지 위에 벡터 요소를 겹친다.
- 나란히 비교 보기에서는 원본과 편집 결과를 같은 크기의 두 패널로 표시하고 결과 패널을 계속 편집한다. 화면 맞춤은 두 패널 전체 폭을 고려한다.
- 원본 투명도 슬라이더, crop/검출 overlay 종류별 토글, 미니맵은 없다.

## 9. 저장·불러오기·내보내기

### 로컬 및 서버 저장

- JSON 파일을 불러와 편집한다. 프런트엔드 최대 JSON 크기는 10 MiB다.
- 불러오기 전 문서 좌표, 요소 종류/ID, relation 참조를 검사한다.
- 프런트엔드 JSON 검사에서는 `arrow_id`가 존재하는지만 확인한다. 해당 요소가 실제 Arrow인지, flows_to source/target이 실제 Box인지 검사는 서버 저장/내보내기 검증에서 추가로 수행한다.
- 저장은 `/api/save`로 보낸다. 서버는 ID/좌표/유형/relation을 추가 검증하고 세션 JSON을 원자적으로 기록한다.
- 문서 열기에서 저장 세션 이름, 요소 수, 수정 시각을 표시한다.
- 세션을 다시 열거나 삭제할 수 있다.
- 분석 세션에는 원본과 전처리 이미지를 저장한다. 브라우저는 `/api/sessions/{id}/image`, `/processed-image`를 참조한다.
- 변경 상태와 페이지 이탈 경고가 있다. 로컬 복구 초안과 편집 후 서버 자동 저장을 지원한다. 버전 비교, 협업/공유 링크는 없다.
- 빈 캔버스 문서는 원본 이미지가 없으므로 세션 목록에서 JSON 복원은 가능하지만 이미지 파일 복원은 없다.

### 파일 내보내기

- JSON, SVG, PNG, PDF를 서버에서 생성해 내려받는다.
- 출력 범위는 요소의 bbox/화살표 endpoint bounds를 기반으로 계산한다.
- PNG/PDF는 CairoSVG 의존성이 필요하다.
- 내보내기 전 미리보기, 해상도/페이지 크기/배경 옵션, 원본 이미지 포함 옵션은 없다.

## 10. 백엔드 API와 오류 처리

| 경로 | 기능 |
|---|---|
| `GET /` | 웹 편집기 HTML |
| `GET /static/*` | CSS/JS 제공 |
| `GET /api/health` | 상태 및 버전 |
| `POST /api/analyze` | 업로드, 전처리, 검출/OCR/관계 분석 |
| `GET /api/sessions` | 저장 문서 목록 |
| `GET /api/sessions/{id}` | 저장 JSON 불러오기 |
| `GET /api/sessions/{id}/image` | 원본 이미지 반환 |
| `GET /api/sessions/{id}/processed-image` | 전처리 이미지 반환 |
| `DELETE /api/sessions/{id}` | 저장 문서 및 이미지 제거 |
| `POST /api/save` | JSON 세션 저장 |
| `POST /api/export/{json\|svg\|png\|pdf}` | 파일 내보내기 |

- 입력 형식 변환은 애플리케이션 파일 크기·픽셀 상한 없이 실행하며 시스템 메모리, 저장 공간, 변환 시간에 제한된다.
- 빈 파일, 읽을 수 없는 이미지, 미지원 이미지 형식, 잘못된 OCR 엔진/장치, 잘못된 문서 구조를 오류 응답으로 처리한다.
- 세션 ID 형식, 요소 ID 중복, 지원하지 않는 요소/도형/relation, 범위 밖 bbox/endpoint, 잘못된 relation 요소 타입을 검증한다.
- 저장은 임시 파일 작성 후 교체하는 방식으로 원자화한다.
- 분석 timeout은 504, 저장 공간 문제는 507, 분석 일반 오류는 500으로 반환한다.
- 프런트엔드는 네트워크 연결 실패와 HTTP 오류 메시지를 토스트/상태 영역에 표시한다.
- 분석 실패 후 표시되는 `분석 다시 시도` 버튼으로 같은 업로드 이미지와 현재 엔진 설정을 재요청한다. 자동 재시도는 하지 않는다.
- 상태 polling, 취소 버튼, 단계별 서버 진행 이벤트, 여러 동시 분석 작업 큐 UI는 없다.

## 11. 남은 범위와 확인 제약

- 분석은 단계별 실제 진행률 대신 작업 중 spinner를 표시한다.
- 직접 원근·밝기·크롭 조절, 자유곡선, 임의 이미지 객체, 그룹/레이어/페이지, 버전 타임라인, 협업 기능은 아직 없다.
- 브라우저 포인터/더블클릭 실제 상호작용 검증은 Chrome Crashpad 권한 오류로 실행하지 못했다. 정적 검사와 ASGI 경로 검증은 별도로 수행했다.

## 13. Visual Paradigm 비교 후 이번 보완 사항

Visual Paradigm Online 공식 기능 소개에서 드래그 기반 도형/연결 편집, 넓은 도형 라이브러리, 격자·정렬 도움, 스타일 조정, 정렬·간격, 회전, 자동 저장을 비교 기준으로 삼았다 ([공식 에디터 기능](https://online.visual-paradigm.com/diagrams/features/online-diagram-editor/), [공식 다이어그램 소프트웨어 기능](https://vp-online.visual-paradigm.com/diagrams/solutions/diagram-software/)).

이번 코드 변경으로 다음을 추가·수정했다.

- 순서도 기호 11종의 미리보기·캔버스 표시·SVG/PDF 출력이 같은 도형 종류를 사용한다. 시작·종료는 캡슐, 입력/출력은 평행사변형, 수동 입력은 사다리꼴로 구분한다.
- 빠른 도형 추가는 선택한 기호를 추가하고, 가능한 경우 기존 요소와 겹치지 않는 빈 위치를 찾는다.
- 도형·텍스트·화살표 도구는 연속 생성 후에도 활성 상태를 유지한다. V/Escape로 선택 모드로 복귀한다.
- 화살표 끝점이 도형 가까이에 있을 때에만 관계를 지정하고, 양 끝이 유효한 도형에 닿으면 도형 경계로 스냅한다. 동일한 방향의 중복 연결은 거부한다.
- 화살표/연결 도구를 켜면 도형의 네 연결 포트를 표시한다. 수동 화살표 끝점 편집과 속성 편집은 가장 가까운 도형에 재연결하며 source/target ID, 방향, 끝 좌표를 함께 갱신한다. 양 끝 연결이 해소되면 해당 수동 미연결 경고도 제거한다.
- 다른 요소에 가까이 이동하면 가장자리·중앙 위치를 정렬 스냅하고 가이드를 표시한다. 격자 스냅과 동시에 적용하지 않는다.
- 보기 전환에 원본/복원 나란히 비교를 추가했다. 두 패널은 같은 문서 좌표계를 사용하고 복원 패널은 편집 가능하다.
- 분석 실패 시 업로드 이미지와 선택된 엔진/장치로 다시 실행하는 버튼을 보여 준다.
- 기본 선형, 조건 분기(예/아니오), 입출력 템플릿을 추가했다. 기존 요소가 있으면 교체 확인을 받고, 생성된 연결도 일반 relation/arrow 데이터로 저장된다.
- 검토 패널에 전체/확인 필요/확인 완료/보류 필터를 추가했다.
- 화살표 속성에서 방향을 반전하면 source/target과 start/end를 함께 바꾼다.
- 화살표 라벨은 속성 패널 또는 더블클릭으로 편집할 수 있고, Shift+Enter 줄바꿈을 표시하며 relation label과 동기화한다.
- 도형 텍스트는 박스 크기에 따라 가능한 범위에서 글자 크기를 줄이고 긴 문자열을 임의로 잘라내지 않는다.
- 선택 요소의 너비/높이를 동일하게 맞추는 명령을 추가했다.
- 서식 복사 도구로 원본 요소의 선/채우기/글자 스타일과 회전을 여러 대상에 연속 적용한다.
- 로컬 복구 초안에 더해 편집 후 서버 자동 저장을 예약한다. 자동 저장 실패는 상태 표시와 재시도로 처리하며 기존 수동 저장을 유지한다.
- 검출 모델의 클래스 이름이 순서도 기호를 나타내면 결과 요소에 해당 기호를 기록한다.

현재 범위 밖인 Visual Paradigm 범용 기능은 자유곡선, 임의 이미지 객체, 그룹/레이어/페이지, 정렬 가이드, 버전 비교, 협업이다. RADU 순서도 복원과 검수에 필요한 생성·이동·크기 변경·텍스트/관계 편집·저장·내보내기는 이 범위와 별도로 유지한다.

정적 검사, 11종 기호의 SVG 파싱 및 서버 스키마 검증, ASGI를 통한 health/home/save/load/SVG export/delete smoke 검증은 통과했다. Chrome 실행은 Crashpad 권한 오류로 종료되어 실제 브라우저 포인터·더블클릭 회귀 검증은 이 환경에서 수행하지 못했다.

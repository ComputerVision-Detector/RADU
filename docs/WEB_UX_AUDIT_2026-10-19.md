# RADU 웹 기능 및 UX 검증 기록

기준: 2026-10-19, 이 저장소의 FastAPI와 브라우저 편집기 코드. `완료`는 코드 경로와 데이터 저장 형식이 연결되었다는 뜻이다. 브라우저에서 직접 조작 검증을 못 한 항목은 별도로 표시한다. Visual Paradigm과 동일한 전체 제품 기능을 제공한다는 뜻은 아니다.

## RADU 고유 흐름 및 파일

| 영역 | 현재 동작 | 검증 범위 |
| --- | --- | --- |
| 분석 | 업로드 후 전처리·검출·선택 OCR·관계 분석. 진행 중 상태와 실패 안내 | API 코드 확인. GPU 모델별 실제 분석은 이 검증 범위 밖 |
| 원본 비교 | 원본·검출 중첩·복원·나란히 비교, 요소 및 관계 검수 패널 | 코드 확인 |
| 관계 검수 | 관계 출발·도착 재지정, 확인·보류·수정 상태, 경고 선택 | JSON 계약 확인 |
| 저장 | 세션 저장·검색·삭제·복제, 브라우저 초안 복구, 이전 버전 조회·복원, 다른 창의 저장과 409 충돌 방지 | ASGI 저장·충돌·이력·복제 확인. 검색 UI는 코드 확인 |
| 공유 | 같은 서버의 세션 URL 복사, 깨끗한 문서 5초 간격 새 버전 확인 | 코드 확인. 사용자별 권한과 동시 편집 병합은 없음 |
| 가져오기 | RADU JSON 유효성 확인 후 재편집 | JSON 계약 확인 |
| 내보내기 | 현재 페이지 JSON/SVG/PNG, 전체 페이지 PDF, 배경 투명·PNG 배율, 출력 미리보기 | ASGI와 XML/PDF 생성 확인 |

## 이번 점검에서 수정한 결함

- 새 도형의 높이 계산에서 시작점 Y 좌표를 잘못 사용하던 문제를 수정했다.
- 수기 이동과 여러 요소 크기 변경에서 화살표 끝점, 펜 좌표, JSON 좌표를 함께 갱신한다.
- 템플릿 전환이 이전에 저장된 세션을 덮어쓰던 경로와 템플릿 아래쪽 도형이 겹치던 배치를 수정했다.
- 잠긴 도형이 더블클릭 텍스트 편집으로 바뀌던 경로를 차단했다.
- 숨긴 레이어나 잠긴 레이어에 새 도형·이미지·펜 선·목록 생성 결과가 생기지 않도록 막았다.
- 도형 팔레트를 끌기 시작할 때 모달을 제거해 드래그가 취소될 수 있던 경로를 수정했다.
- 격자 간격을 바꿔도 생성·크기 변경에 10픽셀을 사용하던 동작을 설정값으로 통일했다.
- 복사한 묶음을 붙여넣을 때 각 요소를 따로 경계에 맞춰 연결선이 어긋나던 동작을 공통 이동량으로 바꿨다. 펜 좌표와 배열형 화살표 끝점도 함께 이동한다.
- 화면 맞춤 이후 창 크기 변경이나 원본 비교 모드 전환에 맞춰 캔버스를 다시 배치한다. 검색 필드가 열린 모달도 `Esc`로 닫을 수 있다.
- 빈 문자열을 임의 기본 문구로 렌더링하던 경로를 수정했다.
- 반복 복제에 선택한 도형 사이의 화살표와 관계를 포함한다.
- 원래 선택했던 글꼴·굵게·기울임을 `style`이 없는 요소에도 저장한다.
- 선 교차 방식, 라벨 줄바꿈, 화살촉 크기를 SVG 출력에도 반영한다.
- 저장 이력을 숫자 개정 번호 역순으로 정렬한다.
- 잘못된 레이어·관계·화살촉·불투명도를 JSON 열기 시 더 일찍 거부한다.
- 손상된 base64 삽입 이미지를 저장·출력 전에 거부하고, 명시적으로 `null`인 서식 값으로 출력이 실패하지 않도록 처리했다.
- 한 화살표가 여러 흐름 관계에 동시에 연결되는 문서를 거부한다.
- 화살표 요소가 빠진 오래된 관계는 도형 경계에 연결해 표시한다. 회전한 이미지·펜 선·화살표도 SVG/PDF에 회전을 반영한다.

## 여전히 미완료 또는 미검증

1. **실제 브라우저 UX 회귀 검증**: 이 실행 환경에서는 Chrome/Firefox 헤드리스가 샌드박스 소켓 제한으로 시작되지 않았다. 더블클릭, 포트 드래그, 확대 상태에서의 이동, 모바일 터치를 브라우저에서 끝까지 조작했다는 근거가 없다.
   정적 파일의 ASGI 직접 요청도 샌드박스 내 스레드 호출에서 지연되어 이 경로의 자동 확인에 포함하지 않았다. Python에서 HTML을 읽고 JavaScript 구문은 별도로 확인했다.
2. **Visual Paradigm 전체 범위**: Visio 가져오기, Office 연동, 팀 권한, 실시간 공동 편집, 댓글, 수식 편집, 사용자 정의 다이어그램 유형, 여러 다이어그램 사이 링크, 고급 도형 병합, 선 교차의 곡선·직각 경로 완전 지원은 없다.
3. **RADU 분석 품질**: 모델 가중치, OCR 서비스 설정, 손그림 데이터에 따라 검출·OCR·관계 정확도가 달라진다. 원본과 복원 간의 모든 오류 유형을 자동으로 찾는 검증기는 아직 없다.
4. **출력 충실도**: 브라우저의 글꼴을 PDF 환경에 항상 똑같이 재현할 수 없다. 이미지 삽입의 모든 파일 코덱을 브라우저와 서버 양쪽에서 검증하지 않았다.
5. **운영 기능**: 세션 URL에는 사용자별 인증/접근 제어가 없다. 외부 공개 서버에서 공유를 제공하려면 별도 권한 모델이 필요하다.

## 실행한 확인

- `deno check`로 프런트엔드 JavaScript 3개 파일의 구문 검사.
- `python -m compileall`과 `git diff --check`.
- 모델 단위로 그룹·페이지 전환·도형 경계·크기 변경·자동 배치·직선 교차 경로 검사.
- 임시 디렉터리를 사용한 ASGI 계약 검사: 저장·재불러오기, 버전 순서, 이전 버전 조회, 409 충돌, 여러 페이지와 이미지 URL을 포함한 세션 복제, 부정확한 데이터 422, SVG·PNG·PDF 출력.
- SVG XML 파싱과 여러 줄 화살표 라벨·화살촉 출력 확인. 2페이지 PDF 페이지 수 확인.
- PNG/JPEG/WEBP 삽입 이미지의 PNG 내보내기 확인. OCR을 끈 합성 순서도 이미지 분석 API 응답 및 문서 유효성 확인.
- PNG/JPEG/WEBP 삽입 이미지를 저장 검증기가 허용하고 손상된 데이터는 422로 거부함을 확인. `null` 서식의 SVG·PNG 출력 확인.

브라우저 검증이 완료되기 전에는 이 문서를 전체 기능 완료 판정으로 사용하지 않는다.

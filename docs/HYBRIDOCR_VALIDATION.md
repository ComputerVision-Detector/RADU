## 검증 한계

처리 경로와 사용자의 편집·다운로드 기능을 검증한 단계다. 정확도 검증을 완료한 OCR 시스템은 아니다. 한국어 손글씨에서 원문 오인식이 남고, Qwen이 불확실 항목을 빈 목록으로 반환해도 실제 오류가 존재했다. 수식·복잡한 표·화살표 연결 구조의 보존도 부족한 표본이 있었다. Qwen이 OCR보다 모든 항목에서 정확하다고 판단할 근거는 없다.

표는 Markdown 표를 표현할 수 있고 PDF에서 표로 렌더링하지만 원본 표를 정확히 복원하는 품질은 별도 평가가 필요하다. 화살표는 본문의 연결 관계 설명으로 표현하며 편집 가능한 도형이나 원본과 동일한 페이지 레이아웃으로 복원하지 않는다. 병합 셀과 복잡한 Markdown/수식 조판은 지원하지 않는다.

정량 평가는 정답 전사·표 셀·연결 관계가 필요하다. 현재 표본에는 그 정답을 만들지 않았고 CER/WER·표 정확도·연결 정확도를 계산하지 않았다. 화면은 자동 검수 결과와 사용자 저장 단계를 구분한다.

웹 작업은 현재 단일 서버 프로세스에서 순차 실행하며 실행 중 서버 재시작 시 작업을 재요청해야 한다. 복사한 가상환경은 기존 환경의 패키지를 `.pth`로 참조하므로 독립 재배포 시 의존성을 다시 설치해야 한다.

검증 산출물: `data/hybrid-smoke/desktop-final.png`, `mobile-final.png`, `browser-download.pdf`, `browser-download.txt`. 작업의 원본·OCR·모델 원문·교정본은 `data/hybrid/<작업 ID>/`에 보존한다.

## 벡터 시각 검수로 전환

현재 기본 검수 UI는 Markdown 본문 편집 대신 `/review/<job ID>`의 SVG 작업실이다. 기존 RADU의 선택·이동·크기 변경·속성·화살표 연결·실행 취소 코드를 재사용하고, HybridOCR 작업 저장소 및 원본 좌표에 연결했다. 표 추가는 사용자가 캔버스에 영역을 그린 후 개별 셀을 편집하는 방식이다. 내부 JSON을 사용자에게 직접 편집하도록 요구하지 않는다.

검증 내용:

- OCR 고정 id와 원본 좌표에 Qwen 교정문을 연결함. 기존 작업은 좌표를 유지하고 높은 유사도 문장만 보수적으로 대응함.
- 새로운 모델 지시로 실제 표본에서 OCR id별 교정 59개를 반환함. 구조 후보 44개(도형 40·화살표 4)와 합쳐 원본 좌표의 벡터 103개로 구성하고 문서 스키마 검증을 통과함. 작업 ID: `2e05f646a9934559b94752ef44a917d7`.
- 초기 실험에서 Qwen의 자유 좌표 생성이 반복되며 토큰 상한에 도달했으므로 해당 방식을 기본 경로에서 제거함. OCR·구조 검출 좌표를 고정하고 Qwen은 텍스트 교정·검수 의견을 반환함. 도형·화살표 검출은 후보이며 정확도 검증 결과가 아님.
- Chrome에서 실제 SVG 포인터 조작으로 텍스트 더블클릭 수정, 드래그 이동, 모서리 크기 변경, 2×2 표 생성 및 셀 편집, 화살표 끝점 변경을 확인함. SVG 재렌더링으로 click 이벤트가 누락되던 기존 문제를 HybridOCR 작업실의 포인터 더블탭 처리로 보완함.
- 수정한 요소 좌표·텍스트·표 셀·화살표가 서버에 저장되고 새로고침 후 유지됨. revision 충돌·범위 밖 좌표 거부·편집 후 사용자 확인 상태 해제 검증.
- PDF는 편집한 벡터를 직접 출력하며 원본 이미지나 편집 핸들을 포함하지 않음. 원본 페이지 좌표·비율을 보존하고 한글 폰트를 포함함. `pdftotext`로 수정한 한글 요소와 셀 내용을 확인함. 줄바꿈은 문서 배치에 따름.
- 데스크톱 1600×1000 및 모바일 390×844 검증에서 JavaScript 오류와 가로 넘침 없음.

브라우저 회귀 검사: `tests/browser/hybrid_vector_review.py`. 검증 산출물: `data/hybrid-smoke/vector-desktop.png`, `vector-mobile.png`, `vector-browser.pdf`, `vector-browser-job.json`.

표 셀은 개별 사각형이므로 인접 셀 경계가 자동으로 함께 움직이지는 않는다. 기존 OCR에 표·화살표 구조가 없다면 작업실에서 수동으로 추가하거나 새 분석의 구조 후보를 사용한다. 모델 추론 성공과 인식 정확도는 구분하며, 원본과 직접 대조해야 한다.
